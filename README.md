# Terraform AWS Get Started Assignment

This repository contains the `.tf` files, screenshots, and learnings from the HashiCorp Terraform AWS Get Started track.

## Completed Tutorials & Key Learnings

**1. What is Infrastructure as Code with Terraform?**
* **Key Learning:** Understood the concept of IaC and how Terraform helps in provisioning infrastructure consistently.

**2. Install Terraform**
* **Key Learning:** Successfully installed the Terraform CLI on my local machine and verified the setup.

**3. Create Infrastructure**
* **Key Learning:** Learned how to write basic `.tf` files, define the AWS provider, and use `terraform init`, `terraform plan`, and `terraform apply`.

**4. Manage Infrastructure**
* **Key Learning:** Learned how to update existing infrastructure configuration and apply changes safely.

**5. Destroy Infrastructure**
* **Key Learning:** Used the `terraform destroy` command to delete all provisioned AWS resources to prevent unwanted billing.

**6. Collaborate using HCP Terraform**
* **Key Learning:** Learned how to configure a `cloud` block to use HCP Terraform for remote state storage.
